# SQLineage identity

Owner requested the SQLineage name and an app icon on 2026-09-07.

The mark combines a database cylinder and two outgoing relationship arrows inside a rounded teal square. Ivory shapes and mint connectors match the warm light/dark application palette. It is a code-native SVG: editable, scalable, and usable without a new font, image-generation dependency or network request.

Asset: `site/public/sqlineage-icon.svg`. The header uses a 32px decorative image beside the visible SQLineage wordmark; the SVG is also the browser favicon. Vite base-aware asset references preserve deployment under repository subpaths. The HTML title and XLSX creator metadata use SQLineage.

The CLI, repository, package identifiers, URLs and historical design documents retain their existing technical names. This is a visible application rebrand; no repository rename or trademark clearance is implied. The palette and branding refinements are local changes after PR #21 was created and have not yet been pushed.
