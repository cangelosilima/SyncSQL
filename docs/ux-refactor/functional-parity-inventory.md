## Additional field and limit contracts

- Object quick facts are Modified (when present), Deps, Used by, and Columns (when present), alongside server → database → optional schema and optional description. They are current catalog metadata even while historical DDL is viewed.
- Full Lineage renders its graph at 70vh and uses graph component default summarization of 60; its separate selection threshold of 300 is not the same limit. Oversized selection breakdown groups by server, database and type, displaying eight groups per axis plus overflow counts.
- Diff calculation rejects either revision above 2,000 lines; identical definitions show the no-differences state before the oversized-result message is considered by the view.
- Metric TrendChart uses shared series scale, null gaps (never interpolated), point date/name/value tooltips, series legend and date range; no finite supplied values displays “No data points yet.” Single snapshots still display a point.

## Exact export contracts

- Object CSV columns, in order: Id, Server, Database, Schema, Type, Name, QualifiedName, Description, Path, SizeBytes, ColumnCount, GrantCount, DependsOnCount, UsedByCount, ChangeCount, LastChangedAt.
- Column CSV: Column, DataType, Description. Grant CSV: Grantee, GranteeType, Permission, State, Column.
- Access CSV: Id, Server, Database, Schema, Type, QualifiedName, followed by grant columns; one permission per row.
- Dependency CSV: Direction, Id, Server, Database, Schema, Type, QualifiedName, ReferencedColumns; both directions; column tags joined with spaces.
- Workbook worksheet headers and field precision are defined in [catalogXlsx.ts](../../site/src/lib/catalogXlsx.ts). Metrics worksheet exports snapshot counts and aggregate fields, not every nested index/statistic measurement; do not assume the current workbook literally captures every chart datum. Definition worksheet is numbered latest-DDL lines; history includes availability metadata rather than all historical DDL bodies. Through-link sheets retain raw references rather than the UI's deduplicated target grouping.
- CSV formatting and workbook escaping/serialization remain governed by [csv.ts](../../site/src/lib/csv.ts) and [xlsx.ts](../../site/src/lib/xlsx.ts); preserve schema, ordering and precision unless separately approved.
